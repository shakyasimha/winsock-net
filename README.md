# winsock-net

A collection of **Windows socket programming experiments and network programming exercises in C** using the Winsock API.

## What I'm Learning

* Windows socket programming
* TCP and UDP communication
* Client-server architecture
* Socket lifecycle and configuration
* Network byte order and serialization
* Blocking and non-blocking sockets
* Concurrent connections
* Basic network protocol implementation

## Tech Stack

* **Language:** C
* **Platform:** Windows
* **Networking API:** Winsock2

## Purpose

This repository is primarily a hands-on exploration of low-level network programming on Windows, with progressively more complex programs built on top of the Winsock API.

## Status

🚧 Work in progress — built for learning, experimentation, and understanding networking at a lower level.
